Scenario

应用场合 · 何时必须用路由器？

场景 A

局域网内

同一局域网内的子网互联，可用三层交换机代替路由器。

场景 B

跨地域

局域网必须与公网互联实现跨地域网络时，路由器不可缺少。

问题

纯交换机的局限

完全构建在交换机上的网络会出现碰撞、堵塞、通信混乱等问题。

方案

路由器

通过路由所具备的功能进行有效的安全控制策略，可避免上述问题。

Project

项目案例 · 直联路由配置模拟实验

环境

Packet Tracer 模拟；2 台路由器 + 2 台 PC + 若干交换机。

互联 3 个网段

网段 A — 路由器 R1 — 路由器 R2 — 网段 B；验证跨段 ping 通。

配置直连路由

为每台路由器的接口配置 IP + 子网掩码；直连路由自动出现。

详见任务卡

按 ① 物理连接 → ② 接口 IP → ③ 静态路由 → ④ 测试 的顺序推进。

Background

相关知识

路由的概念、原理与协议。

Routing

路由选择与路由器

路由选择

选择路径

选择一条路径发送 IP 数据报的过程。

路由器

执行路由的设备

进行路由选择的计算机——工作在网络层。

IP 互联网

由路由器互联

IP 互联网由路由器将多个网络相互联接组成。

自治

面向非连接

采用面向非连接的解决方案；各路由器独立处理每个数据报。

Routing Table

表驱动 IP 选路 · 基本思想

存表

路由表

在需要路由选择的设备中保存一张 IP 路由表。

内容

(N, R) 对

路由表存储可能的目的地址及如何到达目的地址的信息。

查询

按表转发

转发 IP 数据报时查询路由表，决定把数据报发往何处。

决策

下一跳

路由表只需指明下一站，路由器并不知道到达目的地的完整路径。

Table Format

标准的 IP 路由表

下一站

next-hop 选路

路由表仅指定从该路由器到目的地路径上的下一步——不知道完整路径。

(N, R)

目的 — 下一站

路由表包含许多 (N, R) 对序偶：N = 目的网络地址；R = 路径上下一个路由器的 IP。

目的地址

网络级 / 主机级

N 通常是网络地址；特定主机路由才会用主机 IP。

刷新

动态 vs 手工

路由表可以手工建立（静态路由），也可以自动学习（动态路由）。

Route Sources

路由表的建立与刷新

01

静态路由

人工指定的路由——管理员手工建立和管理。

02

动态路由

路由器通过自己学习得到的路由——相互交换路由信息。

03

直连路由

接口配置 IP 后自动出现的路由——无需额外配置。

04

默认路由

「最后兜底」的路由——查不到明细时走这里。

Static

静态路由 · 特点

定义

人工建立

由人工建立和管理的路由。

变化

不会自动变

静态路由不会自动发生变化。

更新

手工维护

拓扑或链路变化时必须手工更新。

优势

安全 + 简单

安全可靠、简单直观，避免了动态路由协议的开销。

劣势

扩展性差

不适用于复杂互联网——维护工作量大、易出现路由环、故障不会自动切换。

Special Routes

路由表中的特殊路由

默认路由

Default Route

路由表没有明确目的网络时，将数据报转发到默认路由指定的路由器。

默认路由·作用

缩短表长

缩短路由表长度、减少路由计算时间——出口路由器的常用做法。

特定主机

Host Route

对单个主机（而非网络）指定一条特别路径。

特定主机·作用

调测 + 安全

增强安全性；用于网络连通性调试与路由表正确性判断。

Dynamic

动态路由 · 特点

自动

自我学习

通过自身学习自动修改和刷新路由表。

开销

持续交换

要求路由器之间不断交换路由信息。

优势

自主 + 灵活

更多自主性与灵活性。

适用

大规模、动态

拓扑结构复杂、网络规模庞大的互联网。

能力

自动避障

自动排除错误路径；自动选择性能更优的路径。

Metric

路径度量值 · metric

定义

路径优劣

metric：表征路径优劣的数值。

原则

越小越好

metric 越小，说明路径越好。

依据

单 / 多特征

可基于路径的一个或多个特征计算。

常用

四类指标

跳数 hop count / 带宽 bandwidth / 延迟 delay / 负载 load。

Protocols

路由选择协议 · 主流两类

RIP

向量-距离

路由信息协议——利用向量-距离算法（Distance-Vector）。

OSPF

链路-状态

开放式最短路径优先——利用链路-状态算法（Link-State）。

收敛

Convergence

所有路由器运行相同、精确的路由信息——快速收敛是路由选择协议的关键指标。

D-V

向量-距离路由选择算法

广播

周期性广播

路由器周期性向相邻路由器广播自己知道的路由信息。

学习

学习路径

告诉邻居「我可以到达的网络 + 距离」。

更新

改写路由表

相邻路由器根据收到的信息修改和刷新自己的路由表。

问题

慢收敛

路径变化需要像波浪一样从相邻路由器缓慢传播出去。

RIP

RIP 协议 · Distance-Vector 实现

算法

向量-距离

RIP 是向量-距离算法在 IP 网络上的直接实现。

规范

内容

规定路由器之间交换路由信息的时间、格式、错误处理等内容。

周期

30 秒

相邻路由器之间每 30 秒交换一次路由信息。

度量

跳数

距离以跳数计算——最多 15 跳，16 跳即不可达。

老化

180 秒

180 秒未刷新则标记为过时——约 6 个刷新周期。

L-S

链路-状态路由选择算法

广播

链路状态

每个路由器周期性向其他路由器广播自己与相邻路由器的连接关系。

建图

拓扑图

每个路由器利用收到的信息画出一张互联网拓扑结构图。

计算

SPF 算法

利用最短路径优先算法计算到达各网络的最短路径。

对比

vs 向量-距离

需要全网拓扑；计算更复杂但收敛快。

OSPF

OSPF 协议 · Link-State 实现

基础

链路-状态

OSPF 以链路-状态算法为基础。

优势

收敛快

收敛速度快；支持服务类型选路。

特性

负载均衡 + 认证

提供负载均衡与身份认证。

适用

大型、复杂

适合规模庞大、环境复杂的互联网——企业、运营商骨干。

Compare

向量-距离 vs 链路-状态

维度向量-距离 (RIP)链路-状态 (OSPF)
拓扑依赖不需要了解全网拓扑需要全网拓扑图
信息来源通过相邻路由器了解路径广播链路状态 + 计算 SPF
收敛速度慢（波纹传播）快（增量更新）
计算复杂度简单复杂
适用规模小型到中型 (10–50 网络)大型到特大型 (50+)

Choose

部署与选择 · 三种场景

场景路由协议特征
小型、单路径、静态 IP静态路由2–10 个网络；单路径；拓扑不变
小型到中型、多路径、动态RIP10–50 个网络；多路径；拓扑随时变
较大型到特大型、动态OSPF50+ 网络；多路径；拓扑随时变；需要快速收敛

经验法则：网络规模 + 变化频率 + 是否需要快速收敛——三者共同决定选哪种。
