PART 01 · Why Networks

没有网络的年代……

A

「我有工资报表需要打印，可是我没有打印机！」

— 只能靠 U 盘在两台电脑之间来回拷贝

这是一个「单台计算机孤立工作」的时代。

Motivation · 01

单机的三大痛点

在没有网络的时代，每台计算机都是一座「孤岛」：

  • 设备无法共享　一台机器的打印机只能服务它自己
  • 数据无法流动　文件必须靠 U 盘在机器之间搬运
  • 协作无法进行　多人同时修改同一份文档几乎不可能

Motivation · 02

把机器连起来之后

网络让用户之间共享信息更为容易，也更有效率。

  • 打印机、文件、数据都可以被多台电脑共同使用
  • 修改可以实时同步，不再依赖人工搬运
  • 协同工作变得可能——邮件、即时消息、在线文档

Motivation · 03

网络给我们带来什么？

🎬 网络娱乐 🛒 网络购物 🔍 信息查询 📰 网络媒体 🏠 智能家居 📞 网络会议 📚 在线课堂 📊 大数据
网络已不再是「可选」，而是现代社会的基础设施——和水、电一样不可或缺。

PART 02 · Definition

什么是计算机网络？

在给出定义之前，先看看网络能做什么。

Definition

计算机网络的定义

利用通信线路将具有独立功能的计算机等设备连接起来而形成的计算机集合， 计算机间可以借助通信线路传递信息，共享软件、硬件和数据等资源。

—— 这个定义包含三个关键词：通信线路、独立功能、资源共享。

Definition · 4 Goals

网络的四大功能

核心

① 数据通信

在不同主机之间传输信息——邮件、文件、消息、视频流。

核心

② 资源共享

硬件（打印机、存储）、软件（应用程序）、数据（数据库）共享。

衍生

③ 分布处理

把一个大任务拆给多台计算机协同完成（如 SETI@home）。

衍生

④ 提高可靠性

多机冗余——一台坏了，其它可顶上。

Definition · 3 Elements

从定义中提炼三个要素

手段

通信设备 + 通信线路

交换机、路由器、双绞线、光纤、无线电波——把机器物理地或逻辑地连起来。

管理

网络软件 + 协议

统一的「语言」与规则——让异构设备彼此理解。

目的

资源共享

数据、软件、硬件可被多台设备共同使用。

PART 03 · Performance

网络的性能指标

怎么判断一个网络「快不快、稳不稳」？

Performance · 4 Metrics

四个核心指标

速度

带宽 Bandwidth

链路每秒能传输的最大比特数，单位 bps / Mbps / Gbps。

延迟

时延 Latency

一个比特从一端到另一端所需时间，单位 ms。光速是物理下限。

吞吐

吞吐量 Throughput

实际每秒成功传输的数据量，受瓶颈与拥塞影响。

可靠

误码率 BER

传输错误比特数 / 总比特数。光纤 < 10⁻¹²，铜缆 ~ 10⁻⁵。

Performance · Latency

时延的四个组成部分

数据从源到目的地，总时延 = 各段时延之和：

发送

发送时延

数据长度 / 带宽。把 n bit 推上链路所需时间。

传播

传播时延

物理距离 / 传播速度。光纤里接近 2×10⁸ m/s。

排队

排队时延

在路由器缓冲区等待转发的时间，随网络拥塞波动。

处理

处理时延

路由器查表、校验、决定转发出口所需时间。

Performance · Compare

带宽 vs 吞吐量：常被混淆

带宽 Bandwidth

理论上的最大速率——链路的「额定速度」。类比：高速公路的设计车流量。

例：100 Mbps、1 Gbps

吞吐量 Throughput

实际可达的数据传输速率——受协议开销、拥塞、错误重传影响。

例：100 Mbps 链路上 FTP 实际 ~ 11 MB/s（≈ 88 Mbps）

类比：带宽是水管直径，吞吐量是实际出水量——直径再大，水压不够也出不来。

PART 04 · Components

网络由什么组成？

从一台机器的视角，看见整张网络。

Components · Hardware

硬件层面：一台机器看出去

终端

计算机 / 终端

发出请求或提供资源的设备：PC、服务器、手机、IoT 设备。

连接

网络线缆

双绞线、光纤、电话线、无线电磁波。

机柜

集线器 / 交换机 / 路由器

把多台设备聚合在一起，转发数据。

接入

ADSL Modem / 光猫

把局域网接入运营商网络的「桥梁」。

机房

机柜与配线架

成百上千条线缆的「中枢神经」。

末端

网卡 / Wi-Fi

每台终端接入网络的「最后一步」。

Components · Logical

通信子网 vs 资源子网

通信子网

负责「把比特送到」

  • 通信设备：集线器、交换机、路由器、ADSL Modem、程控交换机
  • 通信线路：双绞线、电话线、光纤、无线电波
资源子网

负责「提供与使用资源」

  • 提供方：文件共享、Web 服务、打印机共享、应用服务
  • 使用方：浏览网页、下载文件、收发邮件

Components · Software

协议：设备之间的「共同语言」

协议（Protocol）是通信双方必须共同遵守的规则集合—— 语法、语义、时序，回答「说什么、怎么说、什么时候说」三个问题。
  • 语法　数据的结构与格式（字段如何排列）
  • 语义　每个字段的含义（收到后做什么）
  • 时序　事件发生的先后顺序与速率匹配

Components · Standards

标准化组织

协议不是一个人写的——由国际标准组织协调制定。

ISO

国际标准化组织

制定 OSI 参考模型。

IEEE

电气电子工程师学会

802 系列（以太网、Wi-Fi）。

IETF

互联网工程任务组

以 RFC 形式发布互联网标准（TCP/IP、HTTP）。

PART 05 · Transmission

传输介质与方式

数据在网络中如何「跑」起来？

Transmission · Media

传输介质的两大类

有线介质

双绞线　最常用，5 类 / 超 5 类 / 6 类，100 m 内

同轴电缆　早期以太网（10BASE-2/5）

光纤　单模 / 多模，长距离、抗干扰

稳定、抗干扰、距离长，但布线成本高

无线介质

无线电波　Wi-Fi、ZigBee、LoRa

微波　点对点长距（如基站间）

红外 / 激光　短距遥控、特殊场景

灵活部署，但易受干扰、安全性弱

Transmission · Mode

三种通信方式

单工 Simplex

数据只能单向传输。
例：广播、电视。

半双工 Half-Duplex

双向但不能同时。
例：对讲机、集线器。

全双工 Full-Duplex

双向同时进行。
例：电话、交换机、网卡。

现代以太网基本都是全双工——可同时收发，效率翻倍。

Transmission · Switching

三种交换技术

数据在网络节点之间如何转发？

① 电路交换

建立专用通路

传统电话网。占用通路、独占带宽，但建立慢、利用率低。

② 报文交换

整块转发

把整条报文存储转发。延迟大、不适合实时。

③ 分组交换

切成小包

把数据切成分组分别路由——Internet 的基础。

Transmission · Packet Switching

分组交换的两种方式

虚电路（Virtual Circuit）

先建立一条逻辑通路（不独占物理），再传所有分组。

例：ATM、Frame Relay、X.25

数据报（Datagram）

每个分组独立路由，可能走不同路径到达。

例：IP、UDP。简单、健壮

PART 06 · Topology

网络的拓扑结构

把计算机抽象成「点」、通信线路抽象成「线」——形成的几何图形。

Topology · 5 Types

五种基本拓扑

总线型 Bus

所有设备挂在一根主干上。

星型 Star

所有设备连到中心节点。

环型 Ring

设备组成闭合环路。

树型 Tree

星型的层次化扩展。

还有「网状 Mesh」——每两个节点间都有路径，Internet 骨干的典型形态。

Topology · Star

星型：现代局域网的事实标准

[中心交换机/Hub] / | \ / | \ PC1 PC2 PC3 ↑ ↑ ↑ 线缆集中在一个机柜或桌面 Hub

优点：易管理、易扩展、单点故障隔离；缺点：对中心节点要求高、布线多。

家庭路由器 + Wi-Fi、本公司办公网、校园网机房——全是星型或树型。

Topology · Compare

五种拓扑的优缺点对比

拓扑优点缺点典型应用
总线型结构简单、便宜故障即全瘫、瓶颈早期 10BASE-2
星型易管理、易扩展中心节点要求高现代以太网
环型路径确定单点故障全瘫令牌环、FDDI
树型层次化扩展根节点关键校园网、园区网
网状可靠性极高复杂、成本高Internet 骨干

PART 08 · Classification

计算机网络的分类

按覆盖范围划分的三种基本形态。

Classification · Overview

分类方式不止一种

可以按拓扑结构、按地理覆盖范围、按使用对象等多种维度划分。

本课程采用最常见的划分——按覆盖范围分为：

  • 局域网 LAN　Local Area Network
  • 城域网 MAN　Metropolitan Area Network
  • 广域网 WAN　Wide Area Network

三种划分并非绝对，彼此之间存在交叠（如校园网常横跨 LAN 与 MAN）。

Classification · LAN

小范围内的高速私有网络

通常覆盖一间办公室、一栋楼或一个园区，由单个组织自行建设与维护。

覆盖

≤ 2 km

同一建筑或同一园区内。

设备

交换机、Wi-Fi AP

成本低、部署灵活。

场景

校园网、办公网

最常见的网络形态。

Classification · MAN

一座城市之内的「中型」网络

覆盖范围介于 LAN 与 WAN 之间，通常由电信运营商或市政府承建。

覆盖

2 – 10 km

同一座城市之内。

技术

光纤、Metro Ethernet

承载能力大于 LAN。

场景

城市政务网、教育城域网

连接多个局域网。

Classification · WAN

跨越城市、地区甚至全球

由运营商承建，使用长途传输链路，是 Internet 的主干。

覆盖

≥ 10 km ～ 全球

跨城市、跨国家、跨洲。

技术

光纤、卫星、海底光缆

传输距离极远，延迟不可忽视。

场景

Internet、跨国专网

我们日常使用的网络都建立在 WAN 之上。

PART 09 · Architecture

对等与主从

两种工作方式：网络中的「身份」由角色决定，不由机器决定。

Architecture · Compare

对等（P2P） vs 主从（C/S）

对等 P2P

每台机器既是客户也是服务器。

  • 地位平等
  • 提供 / 消费资源
  • 家庭多机文件共享

主从 C/S

有明确的服务器与客户端角色。

  • 中心服务器统一管理
  • 性能、安全、可扩展
  • 企业网、互联网主流

主从 ≠ C/S：C/S 描述这一次交互，主从描述网络中的角色分工。

Architecture · Diagram

C/S 服务的提供与请求

客户端

← 响应

Server
  • 客户端主动发起请求
  • 服务器被动响应、提供资源或服务
  • 常见协议：HTTP、FTP、SMTP、POP3

Recap

今天我们学到了什么

  1. 为什么需要网络　单机痛点 → 数据通信 + 资源共享
  2. 网络的定义　通信线路 + 独立设备 + 协议 → 资源共享
  3. 性能指标　带宽 / 时延 / 吞吐量 / 误码率
  4. 组成　硬件 + 软件 + 协议（通信子网 + 资源子网）
  5. 传输　介质（有线/无线）+ 方式（单工/半双工/全双工）+ 交换（电路/报文/分组）
  6. 分类　LAN / MAN / WAN — 距离决定技术与成本
  7. 工作方式　对等 vs 主从，核心是「这一次谁提供服务」
  8. 历史　50s 远程联机 → 90s Internet → 5G / 云计算 / AI
