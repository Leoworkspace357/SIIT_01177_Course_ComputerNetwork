Scenario

应用场景 · 跨 VLAN 互通

01

网段与 VLAN

划分两个 VLAN：VLAN2 = 192.168.1.0/24，VLAN3 = 192.168.2.0/24。

02

网关

为交换机上的两个 VLAN 配置 IP 地址，作为各自网段的网关。

03

互通诉求

VLAN2 内主机需要访问 VLAN3 内的服务器——需要路由来打通。

04

方案

三层交换——用交换机自身完成 VLAN 间路由，性能高、成本低。

Solution

解决方案

VLAN 可以把一个大的广播域划分成几个小的广播域，提高网络效率、保障网络安全。

做法：先划分 IP 网段；将不同网段地址分配给不同 VLAN；为交换机上的 VLAN 配置 IP 地址——两个 VLAN 的 IP 地址就是各自网段的网关；最后启用交换机的三层路由功能，完成 VLAN 间转发。

Steps

具体实现 · 五步走

01

搭建实验环境

一台三层交换机 + 两台 PC；PC1 在 VLAN2、PC2 在 VLAN3，分别接 F0/3、F0/6。

02

设置 IP 地址

PC1 = 192.168.1.1/24，PC2 = 192.168.2.1/24；网关暂不设。

03

划分 VLAN

创建 VLAN2、VLAN3；把 F0/3 划入 VLAN2，F0/6 划入 VLAN3。

04

启用三层交换

ip routing 开启路由；为 VLAN2、VLAN3 配置 IP 作为网关。

05

测试

先 ping 网关验证，再 ping 跨 VLAN 主机——应当全部通。

CLI

启用三层交换 · 关键命令

  • Switch(config)# ip routing　启动交换机的路由功能
  • Switch(config)# interface vlan 2　切换到 VLAN 2 接口
  • Switch(config-if)# ip address 192.168.1.254 255.255.255.0　配置 VLAN 2 的网关 IP
  • 同理为 VLAN 3 配置 192.168.2.254 255.255.255.0
  • end 退出，show ip route 查看路由表确认直连路由

Test

测试 · 从 PC1 ping 网关与跨 VLAN

01

ping 网关

ping 192.168.1.254 —— 验证本机到网关连通。

02

ping 跨 VLAN

ping 192.168.2.1 —— 验证跨 VLAN 主机连通。

03

观察 TTL

跨 VLAN 转发后 TTL 通常从 128 减为 127，说明经过了一跳路由。

04

结论

三层交换成功扮演VLAN 间路由器——互通性能远高于外部路由器。

Background

相关知识 · 三层交换的引入

为什么需要三层交换？

Why L3

三层交换机的引入背景

问题

VLAN 间的转发

划分 VLAN 后需要为 VLAN 之间提供转发能力。

传统

路由器方案

传统 LAN 用路由器完成 VLAN 间转发——但存在成本和瓶颈问题。

演进

三层交换

三层交换技术初步解决了这一问题，并迅速普及应用。

优势

兼具两者之长

既保持交换机的高性能，又具有路由能力——是 VLAN 间通信的标配。

Use Case

三层交换机的应用场景

定位

企业核心

主要用于企业网核心层——承担 VLAN 间路由与高速转发。

能力

完整路由功能

能够实现路由器的全部功能：静态路由、RIP、OSPF、ACL 等。

对比

vs 路由器

三层交换 = 交换机速度 + 路由器智能；专用路由器更适合广域网与边界。

演进

多层交换

现代园区网核心已演进到多层交换——融合路由、策略、QoS、安全。

Principle

三层交换的工作原理 · 一次路由，多次交换

01

首包

第一个数据包走路由（CPU 查表、转发）；同时缓存「MAC + 出接口」映射。

02

后续

同一流的后续包直接由硬件 ASIC 按缓存的映射交换转发，不再经过路由。

03

效果

速度接近二层交换，又具备三层路由的智能——这就是「一次路由，多次交换」。

04

要点

三层交换机在内部完成路由决策，对外仍呈现交换机的形态与速度。

Recap
