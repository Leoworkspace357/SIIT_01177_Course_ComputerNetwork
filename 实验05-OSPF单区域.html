BG · 01

背景 · OSPF 概述

OSPF（Open Shortest Path First）：基于「链路-状态」算法。

- 度量：Cost（默认基于接口带宽，参考 100 Mbps） - 层次化：Area 0（Backbone）+ 其它 Area - 收敛：远快于 RIP（秒级） - 管理距离：110 - 协议号：OSPF 直接封装在 IP 中，IP 协议号 89

BG · 02

背景 · OSPF 五种报文

| 报文 | 作用 | |---|---| | HELLO | 发现 / 维持邻居 | | DD | 描述本地 LSDB | | LSR | 请求 LSA | | LSU | 发送 LSA | | LSAck | 确认 LSA |

BG · 03

背景 · OSPF 关键命令

常用命令：

TIP

反掩码（通配符掩码）：与子网掩码相反。0 = 必须匹配，1 = 任意。例：0.0.0.255 表示前 24 位必须匹配，后 8 位任意（等价于 /24 子网）。

STEP 01

搭建拓扑

  • PT 6.2 新建 Lab5-OSPF.pkt。
  • 拖设备、连线（同 Lab 3/RIP）。
  • Serial DCE 端配 clock rate 64000。
  • PC 的 IP 与网关按地址规划表配置。
STEP 02

基本配置（同 Lab 3）

  • 每台路由器配置 hostname、密码、接口 IP。
  • DCE 端 Serial 配 clock rate 64000。
  • PC 设 IP、子网掩码、网关。
STEP 03

启动 OSPF 进程（R1）

  • 在 R1 CLI：
  • enable → configure terminal
  • router ospf 1 — 启动 OSPF 进程
  • router-id 1.1.1.1 — 设置 Router-ID
  • network 192.168.1.0 0.0.0.255 area 0 — 宣告 LAN1
  • network 10.1.0.0 0.0.0.255 area 0 — 宣告串口链路
  • passive-interface FastEthernet0/0 — LAN 口不发 Hello
  • end → write memory
STEP 04

R2 启动 OSPF

  • router ospf 1 → router-id 2.2.2.2。
  • network 10.1.0.0 0.0.0.255 area 0、network 10.2.0.0 0.0.0.255 area 0、network 192.168.2.0 0.0.0.255 area 0。
  • passive-interface FastEthernet0/0。
  • end; write memory。
STEP 05

R3 启动 OSPF

  • router ospf 1 → router-id 3.3.3.3。
  • network 10.2.0.0 0.0.0.255 area 0、network 192.168.3.0 0.0.0.255 area 0。
  • passive-interface FastEthernet0/0。
  • end; write memory。
STEP 06

验证邻居建立

  • 每台路由器：show ip ospf neighbor。
  • R1 应看到 R2（Neighbor ID 2.2.2.2, State FULL）。
  • R2 应看到 R1 和 R3 都为 FULL。
  • R3 应看到 R2（Neighbor ID 2.2.2.2, State FULL）。
  • 状态机：DOWN → INIT → 2-WAY → EXSTART → EXCHANGE → LOADING → FULL。
STEP 07

观察 LSDB（链路-状态数据库）

  • show ip ospf database。
  • 应看到多种 LSA 类型：
  • Router LSA（Type 1）：每台路由器宣告自己的链路。
  • Network LSA（Type 2）：DR 在多路访问网段上宣告。
  • Summary LSA（Type 3、4、5）：ABR 汇总（单区域实验中较少）。
STEP 08

观察路由表

  • show ip route。
  • 应看到 O 条目：O 192.168.2.0/24 [110/...] via 10.1.0.2。
  • show ip ospf interface brief 查看 OSPF 接口。
STEP 09

连通性测试

  • PC1 ping PC3：通；TTL ≈ 126（跨 2 跳 OSPF 路由器）。
STEP 10

观察 OSPF 收敛速度（关键对比）

  • 把 R2 的 S0/0/1 关闭 shutdown。
  • 几乎立即（< 几秒），R3 的路由表中 192.168.1.0/24 切换到失效。
  • show ip ospf neighbor 中 R2 状态变为 DOWN。
  • 重新 no shutdown——几秒内 FULL 状态恢复，路由同步完成。
  • 对比 RIP：180 秒超时 → OSPF 仅几秒。
STEP 11

进阶 · 修改 Cost 影响选路

  • 在 R1 上手动改 S0/0/0 的 Cost：
  • interface Serial0/0/0 → ip ospf cost 100。
  • 观察 R1 → 192.168.3.0 仍走 R2；如果有等价路径则会重新选路。

ERR · 01

常见错误与排错

邻居卡在 INIT

单向 Hello → 检查 ACL / 接口 / 物理链路。

邻居卡在 EXSTART / EXCHANGE

MTU 不一致（生产环境常见，PT 6.2 一般无此问题）→ 调 MTU。

邻居卡在 2-WAY（多路访问网段）

需 DR 选举 → 等候或调整优先级。

邻居完全建不起

area 不匹配 → 检查 show ip ospf interface 的 area ID。
