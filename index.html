从 网络协议 到 VLAN 与 OSPF，系统掌握计算机网络。

本课程通过 17 章课堂演示 + 6 个实验项目，覆盖计算机网络的核心概念、协议分层、IP 地址与子网、VLAN、DHCP、静态/动态路由（OSPF/RIP）、DNS/WWW 服务等关键内容。配套浏览器内幻灯片放映，支持键盘快捷键与动画演示。

课程模块

按照"基础概念 → 协议分层 → 协议详解 → 网络架构与设备"的认知顺序组织。

4 个模块
01

基础概念篇

介绍网络协议的历史发展脉络，从 1970 年代到现代的重要里程碑事件，理解协议诞生的背景与标准化进程。

第 1 章 协议历史
02

协议分层模型

深入讲解 TCP/IP 四层模型与 OSI 七层模型，每一层都配有详细的协议说明和功能介绍，包括以太网、IP、TCP、UDP 等核心协议。

第 2 章 TCP/IP OSI
03

网络协议详解

涵盖网络层、传输层、应用层各类重要协议的原理和应用场景，包括 IP 地址分类与子网划分、TCP 三次握手、HTTP/HTTPS、DNS 解析等。

第 3 ~ 7 章 IP / TCP / HTTP DNS
04

网络架构与设备

介绍集线器、交换机、路由器等设备的工作原理和在协议栈中的层次定位，配套 VLAN / DHCP / 静态路由 / OSPF 等实战配置章节。

第 8 ~ 17 章 VLAN OSPF
