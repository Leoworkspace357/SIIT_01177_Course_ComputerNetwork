# SIIT 42160 计算机网络 · 课程演示文稿

## 项目简介

本项目是苏州工业职业技术学院“计算机网络”课程（SIIT 42160）的交互式演示文稿，全套 17 章主线内容均以 HTML 幻灯片形式呈现，浏览器内即可放映，支持课堂讲解与学生课后自学。

## 内容结构

课程按主线划分为 17 章，由浅入深覆盖理论、协议、组网与综合实战：

**一、基础与协议（01–06）**

- 01 计算机网络基础知识
- 02 网络协议与分层
- 03 TCP/IP 协议族
- 04 认识 IP 地址
- 05 子网编址
- 06 常见的网络协议及网络命令

**二、局域网与交换（07–10）**

- 07 认识局域网
- 08 网线制作
- 09 配置 VLAN
- 10 VLAN 互通

**三、路由与动态路由（11–15）**

- 11 DHCP 服务器的配置
- 12 路由配置
- 13 使用静态路由实现网络互通
- 14 动态路由 — RIP
- 15 使用 OSPF 实现单区域内网络互通

**四、服务与综合实战（16–17）**

- 16 WWW 和 DNS 服务
- 17 小型办公网络综合实战

## 使用说明

### 环境要求

- 现代浏览器（Chrome、Firefox、Edge、Safari 等）
- 无需安装依赖或构建步骤，直接双击 HTML 文件或通过 `index.html` 进入课程主页即可运行

### 操作指南

- **方向键**（← / →）：切换上一页 / 下一页幻灯片
- **空格键**：下一页
- **ESC 键**：展开 / 收起侧边栏导航
- **数字键**：快速跳转到指定页码
- **鼠标滚轮**：上下翻页
- **H 键**：调出键盘快捷键帮助

### 演示功能

- 幻灯片切换动画与内容渐显效果
- 进度条显示当前播放位置
- 页码计数器实时显示当前位置
- 侧边栏导航可快速定位任意章节
- 响应式布局，适配不同屏幕尺寸

## 技术实现

本项目基于原生 HTML、CSS 和 JavaScript 开发，不依赖任何第三方框架：

- **HTML5 语义化结构**：构建幻灯片内容
- **原生 CSS 动画**：实现平滑切换与渐显效果（`theme.css`）
- **可复用组件样式**：统一的视觉与交互组件（`components.css`）
- **键盘事件处理**：完整的键盘快捷键支持
- **响应式设计**：适配课堂投影、笔记本、平板等不同屏幕
