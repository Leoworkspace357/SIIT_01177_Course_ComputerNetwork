PART 01

任务情境 · VLAN 是孤岛

划 VLAN 解决了广播,但也带来了「部门隔离」的问题——

Problem

VLAN 间的孤岛问题

现象

研发部 ping 不通销售部

Alice 在 VLAN 10,Bob 在 VLAN 20,虽然在同一 Switch 上,但完全不通。

原因

VLAN 隔离

VLAN 是二层隔离——不同 VLAN 不能直接互通,需要三层设备。

诉求

部门间也能通信

某些情况下需要跨部门协作——研发需要销售数据,人事需要财务工资——不能完全隔离。

方案

单臂路由 / 三层交换

使用三层设备(路由器或三层交换机)实现 VLAN 间互通。

PART 02

相关知识

为什么 Switch 自己不能互通 VLAN?——因为缺少三层转发。

Why Router

为什么 Switch 自己不能互通 VLAN?

二层局限

不识别 IP

普通 Switch 只看MAC 地址——不同 VLAN 的 IP 包无法在二层转发。

需要三层

路由器介入

路由器看IP 地址——根据 IP 包的目的地址选路。

网关

每个 VLAN 一个

每个 VLAN 需要一个网关 IP——主机发往其他 VLAN 的包都先发给网关。

解决

路由器 / 三层交换

只要有三层设备,就能打通 VLAN。

PART 03

两种方案对比

单臂路由 vs 三层交换——两种实现 VLAN 互通的方式。

Methods

VLAN 互通的两种方式

方式 A

单臂路由

外置路由器,通过Trunk连 Switch;

用子接口(Sub-interface)处理 VLAN 标签;

→ 适合小规模、预算有限

方式 B

三层交换

三层交换机内置SVI(VLAN 接口);

硬件 ASIC 转发,速度线速;

→ 适合中大型企业

单臂路由 · 带宽计算

计算 · 单臂路由带宽瓶颈

计算 · 规模扩大与性能对比
01
VLAN 数量增加 每个 VLAN 可用带宽 ↓ 5 VLAN → 平均 20Mbps/VLAN 效率下降

Router 的一条物理链路同时承载多个 VLAN——通过子接口实现。

Sub-interface

子接口 · 虚拟的三层接口

  • Router 一条物理链路可虚拟出多个子接口
  • 子接口格式:Fa0/0.10、Fa0/0.20……
  • 每个子接口对应一个 VLAN
  • 子接口 IP 即为该 VLAN 的网关
  • 子接口要封装 802.1Q:encapsulation dot1Q 10
  • 所有 VLAN 共用一条物理链路——带宽是瓶颈

Lab Setup

单臂路由实验 · 5 步

  1. Packet Tracer 新建 Lab11-InterVLAN.pkt
  2. 拖入 1 Switch + 1 Router + 4 PC
  3. PC1-2 接 VLAN 10 (Fa0/1-2);PC3-4 接 VLAN 20 (Fa0/3-4)
  4. Router Fa0/0 接 Switch Fa0/24 —— 设为 Trunk
  5. 配置 Router 子接口,PC 配网关

Router Config

Router 配置 · 完整 CLI

Router>
Router> enable Router# configure terminal Router(config)# interface fa0/0 Router(config-if)# no shutdown Router(config-if)# exit Router(config)# interface fa0/0.10 Router(config-subif)# encapsulation dot1Q 10 Router(config-subif)# ip address 192.168.10.1 255.255.255.0 Router(config)# interface fa0/0.20 Router(config-subif)# encapsulation dot1Q 20 Router(config-subif)# ip address 192.168.20.1 255.255.255.0 Router(config-subif)# end

SVI

三层交换机方案 · SVI 接口

  • SVI = Switched Virtual Interface —— 每个 VLAN 一个虚拟接口
  • 在三层交换机上直接创建:interface vlan 10
  • 配置 IP 作为 VLAN 的网关
  • 无需外置路由器——一台 Switch 同时做二三层
  • 硬件 ASIC 转发,延迟 < 微秒级
  • 现代企业网主流选择

SVI Config

三层交换机 SVI 配置

Switch (Layer 3)>
Switch> enable Switch# configure terminal Switch(config)# ip routing ! 启用三层路由功能 Switch(config)# interface vlan 10 Switch(config-if)# ip address 192.168.10.1 255.255.255.0 Switch(config-if)# no shutdown Switch(config)# interface vlan 20 Switch(config-if)# ip address 192.168.20.1 255.255.255.0 Switch(config-if)# end Switch# show ip route

Case

案例 · 单臂路由不通

故障现象

配置完单臂路由后,PC1 (VLAN 10) ping 不通 PC3 (VLAN 20)。

步骤 1 · 检查封装

Router 子接口上是否有 encapsulation dot1Q 10?漏配 → 标签不识别。

步骤 2 · 检查网关

PC1 的网关是否设为 192.168.10.1?网关错则包不会发给 Router。

步骤 3 · 检查 Trunk

Switch 的 Fa0/24 是否为 Trunk 模式?Access 模式只能承载一个 VLAN。

结论

✅ 封装 + 网关 + Trunk 三件套,缺一不可。
