Scenario

任务情境 · 公司又慢了

扩张

规模扩大

Alice 与 Bob 的公司规模越来越大，部门越来越多。

症状

传输越来越慢

老员工纳闷：计算机配置越来越高，文件传输却越来越慢。

诉求

网络改造

网络改造的呼声越来越高——如何优化、解决拥堵？

答案

VLAN

把一个大的广播域切成多个小的逻辑网络，让广播范围可控。

Solution

解决方案 · VLAN

现状

仍是一个广播域

交换式局域网隔离了冲突域，但所有主机仍处于同一广播域，广播会泛洪到每一台主机。

方案

VLAN 划分

管理员根据实际应用与管理的需要，把局域网划分为多个小的逻辑网络。

效果

隔断广播

VLAN 内部的广播与单播流量不会转发到其他 VLAN，隔断不同 VLAN 间的广播。

价值

控制流量 + 安全

有助于控制流量、减少设备投资、简化管理、提升安全性。

Concept

VLAN 是什么？

定义

逻辑广播域

VLAN 是一种逻辑广播域，可以跨越多个物理 LAN 网段。

分组

按逻辑分组

按逻辑功能、项目组、应用程序来分组工作站，无需考虑用户的物理位置。

示例

学生卡

学生持红卡或蓝卡；只能与同色卡的学生「说话」——就被逻辑分成了两个 VLAN。

作用

限制广播 + 分组

VLAN 可以限制广播；不同 VLAN 中的设备相互不可见。

Objectives

通过本次课，
你将能够：

  1. 认识 VLAN　理解什么是虚拟局域网及其作用
  2. 学会配置 VLAN　在交换机上创建 VLAN 并将端口分配给 VLAN
  3. 了解 VLAN 的划分方法　基于端口 / MAC 地址 / 网络层

Task 01

任务一 · 认识 VLAN

01

定义

VLAN 是一种逻辑广播域，可以跨越多个物理 LAN 网段。

02

分组原则

按逻辑功能、项目组或应用程序分组工作站，不依赖物理位置。

03

运行特点

每个 VLAN 像独立 LAN 一样运行；可在一台或多台交换机上。

04

类比

学生持红卡或蓝卡——只能与同色卡的学生「说话」——这就是两个 VLAN。

Task 02

任务二 · 配置 VLAN · 步骤概览

01

搭建实验

设置 PC0 = 192.168.1.2、PC1 = 192.168.1.3；先 ping 验证同网段互通。

02

创建 VLAN

「配置」 → VLAN 数据库 → 添加 VLAN2；将端口分别加入 VLAN。

03

测试隔离

再用 ping 测试两台 PC——同 VLAN 通，不同 VLAN 不通。

04

结论

VLAN 隔离广播——同一 VLAN 内的计算机可互通，不同 VLAN 不可互通。

Notes

配置 VLAN 注意事项

!

VLAN1

VLAN1 是交换机默认的 VLAN，既不能创建也不能删除；所有端口默认都属于 VLAN1。

!

命名

VLAN 命名应规范，如 VLAN10 = 行政、VLAN20 = 研发。

!

中继

跨交换机的 VLAN 需要中继端口（Trunk）——下一章会学到。

Observation

实验观察 · VLAN 的运行特点

每个 VLAN 就像独立的 LAN 一样运行；一个 VLAN 可以跨越一台或多台交换机，主机设备如同位于同一个网段中。

VLAN 主要有两项作用：限制广播——把广播控制在 VLAN 内部；分组设备——不同 VLAN 的设备相互不可见，提供基础的网络隔离与安全。

Part 02

VLAN 的划分方法

三种常见的 VLAN 划分方式：基于端口、基于 MAC、基于网络层。

3 Methods

常见的 VLAN 划分方式

01

基于端口

按交换机端口划分——最常见、最简单。

02

基于 MAC 地址

按终端的 MAC 地址划分——节点移动后 VLAN 资格保持。

03

基于网络层

按 IP 子网或协议划分——最灵活，也最复杂。

Port-based

基于端口的 VLAN 划分

原理

端口归组

网络管理员针对交换机的端口重新分配组合到不同逻辑网段。

优点

简单稳定

无需考虑端口所连设备是什么；配置简单、清晰。

局限

不够灵活

用户更换物理位置时，需要重新配置端口。

适用

PC 直接接入

最适合「每端口一台 PC」的接入层场景。

Port-based · Edge

边界情况 · 端口接的是 HUB

情况

端口接 HUB

交换机端口连接的是集线器。

原理

共享介质

HUB 是共享介质的多用户网络。

结论

整 HUB 一组

按端口划分只能把整个 HUB下的所有用户划分到同一个 VLAN。

解决

改用 MAC 划分

要让 HUB 下的不同用户进不同 VLAN，需要基于 MAC 地址的 VLAN。

Port Grouping

端口分组的特点

范围

可跨交换机

一组端口可在一台交换机上，也可跨越几台交换机——前提是配置中继。

广播域

组内互通

同一 VLAN 内的所有终端共享一个广播域，相互可通信。

跨 VLAN

需要路由

不同 VLAN 之间通信必须经过路由（路由器或三层交换机）。

实践

接入层标配

端口 VLAN 是接入层最常见的方案，配置简单、易排错。

MAC-based

基于 MAC 地址的 VLAN

原理

MAC 绑定 VLAN

交换机维护「终端 MAC + 端口 + VLAN」对应表，新终端入网时自动归入对应 VLAN。

优势

移动友好

终端物理位置变化不影响 VLAN 归属——MAC 不变，VLAN 不变。

解决

HUB 细粒度

可把同一 HUB 下的不同用户划分到不同 VLAN——端口 VLAN 做不到。

局限

维护成本

MAC 地址毫无规律，建表与维护工作量较大。

Network-based

基于网络层地址的 VLAN

原理

按子网 / 协议

使用协议或网络层地址（如 TCP/IP 子网）确定 VLAN 成员。

优势

协议层分组

可按传输协议划分网段；用户自由移动无需重新配置。

性能

减少延迟

减少协议转换造成的网络延迟。

前提

防 IP 盗用

需要明确两件事：IP 盗用问题；并非所有设备都支持。

Exercise · Large

实践练习一 · 按部门划分 VLAN

部门

5 个部门

研发部、销售部、财务部、生产管理部、人事部——作为 VLAN 划分依据。

目标

广播域控制

让广播流量控制在部门内部，提高网络性能。

地址

172.16.X.0

使用地址段 172.16.X.0，每个部门占一段。

验证

同部门通 / 跨部门不通

用 ping 验证：同 VLAN 通、不同 VLAN 不通——直到下一章用三层交换解决互通。

Exercise · Project

实践练习二 · 按项目组划分 VLAN

分组

两个项目组

PC0 与 PC2 为项目组 A；PC1 与 PC3 为项目组 B。

目标

VLAN 实现

通过 VLAN 实现——组内互通、组间隔离。

地址

172.16.1.0/24

4 台 PC 共用 172.16.1.0/24 网段，但分属不同 VLAN。

提示

不同 VLAN 同子网

即使 IP 在同一子网，不同 VLAN 默认不能直接 ping 通——这是关键观察。
