PART 01

任务情境 · 手动配 IP 的痛

当公司规模扩大到 100 人时——

Problem

手动配 IP 的 4 个痛点

痛点 1

工作量大

100 台 PC 一台台配 IP、子网、网关、DNS——几天都配不完。

痛点 2

易冲突

手输容易重复 IP——两台机配同一地址 → 都上不了网。

痛点 3

难统一

DNS、网关配置各不相同——有人漏配,访问就出问题。

痛点 4

难追踪

谁用了哪个 IP?找不到记录——网络管理混乱。

Task 01

任务一 · 安装 DHCP 服务

环境

Windows Server 2019

使用 Windows Server 作为DHCP 服务器——稳定的图形化配置界面。

步骤 1

服务器管理器

打开「服务器管理器」→「添加角色和功能」。

步骤 2

勾选 DHCP 服务器

在「服务器角色」列表中勾选 DHCP Server。

步骤 3

下一步到完成

按向导一路「下一步」,最后「安装」——重启后生效。

Install

安装步骤 · 截图演示

  1. 服务器管理器 → 仪表板 → 添加角色和功能
  2. 安装类型 → 基于角色或基于功能的安装
  3. 服务器选择 → 选择本机(一台服务器)
  4. 服务器角色 → 勾选 DHCP 服务器
  5. 功能 → 默认即可,「下一步」
  6. DHCP 服务器 → 阅读说明,「下一步」
  7. 确认 → 安装——等待 1-2 分钟
  8. 安装完成 → 服务器管理器显示黄色警示(待配置作用域)

Task 02

任务二 · 创建作用域

开始

DHCP 控制台

开始菜单 → 管理工具 → DHCP——展开服务器节点。

新建

新建作用域

右键「IPv4」→「新建作用域」——按向导配置。

名称

研发部作用域

名称:研发部;描述:为研发部门分配 IP。

范围

192.168.10.0/24

起始 IP:192.168.10.1;结束 IP:192.168.10.254。

Scope Config

作用域配置 · 6 步

  1. 名称与描述
  2. IP 范围:192.168.10.1 – 192.168.10.254
  3. 排除地址:192.168.10.1 – 192.168.10.10(服务器保留)
  4. 租约期限:默认 8 天(可改)
  5. 配置 DHCP 选项:
    • 默认网关:192.168.10.1
    • DNS 服务器:192.168.10.1 或外网 DNS
  6. 激活作用域

Activate

激活作用域 · 关键一步

  • 创建完作用域后默认是未激活(红色向下箭头)
  • 右键作用域 → 激活
  • 状态变为绿色向上箭头——开始「对外服务」
  • 未激活的作用域不会响应客户端请求
  • 可以同时创建多个作用域,逐一激活

Task 03

任务三 · 客户端验证

  1. 客户端 PC 设 IP 自动获取(默认即如此)
  2. 命令行执行 ipconfig /release 释放旧 IP
  3. 执行 ipconfig /renew 重新获取
  4. 查看 IP / 子网掩码 / 网关 / DNS 是否自动获得
  5. 在 DHCP 控制台查看「地址租约」是否新增
  6. 跨网段测试:不同作用域的 PC 应获得不同子网 IP

PART 03

DHCP 原理

DHCP 是怎么「魔法般」把 IP 发给客户端的?

DORA

DHCP 4 步租约 · DORA

STEP 01
DHCP Discover
客户端广播「有 DHCP 服务器吗?」
STEP 02
DHCP Offer
服务器广播「我可以给 192.168.10.50」
STEP 03
DHCP Request
客户端广播「我要 192.168.10.50」
STEP 04
DHCP ACK
服务器广播「确认,租约开始」

首次获取时四步以广播为主(Offer / ACK 实际可单播到客户端 MAC)——直到 ACK 后,客户端才拥有完整的 TCP/IP 配置;续租阶段 T1 为单播(向原服务器)、T2 为广播(向任意服务器)。

Discover

Step 1 · DHCP Discover

  • 客户端刚开机,还没有 IP
  • 广播地址 255.255.255.255,源端口 68 → 目的端口 67
  • 包含自己的 MAC 地址
  • 报文类型:DHCP Discover
  • 含义:「我是新来的,谁能给我一个 IP?」

Offer

Step 2 · DHCP Offer

  • DHCP 服务器收到 Discover,检查地址池
  • 从可用地址中选一个(如 192.168.10.50)
  • 广播 Offer 报文,包含:
    • 分配的 IP 地址
    • 子网掩码 / 网关 / DNS
    • 租约期限(默认 8 天)
  • 可能有多个服务器响应——客户端选第一个

Request

Step 3 · DHCP Request

  • 客户端选好一个 Offer
  • 广播 Request 报文
  • 告诉所有人:「我选了 192.168.10.50」
  • 其他未选中的服务器收回自己的 Offer
  • 被选中的服务器记录这次租约

ACK

Step 4 · DHCP ACK

  • 选中的服务器发送 ACK(确认,通常单播到客户端 MAC)
  • 包含最终配置:IP、掩码、网关、DNS、租期
  • 客户端收到 ACK 后正式启用该 IP
  • 服务器在 租约表 中记录:
    • MAC 地址
    • 分配的 IP
    • 租约开始/到期时间

Renew

租约续期 · 50% / 87.5% 计算

计算 · DHCP 租约续期时间窗(默认 8 天)
01
总租期 8 天 = 8 × 24 × 3600 = 691200 秒 Lease Time = 691200 s
02
T1 时点(50%) 4 天 = 345600 秒 → 客户端发起 RENEW 单播到原服务器
03
T2 时点(87.5%) 7 天 = 604800 秒 → 客户端广播 DHCPREQUEST 向任意服务器续约

Renew

租约续期 · 时间轴与工程经验

计算 · 到期与租期选择
01
到期(100%) 8 天 = 691200 秒 → 客户端必须停止使用 IP 若未续约
02
实际工程 短租期(几小时)适合移动办公 长租期(几天)适合固定终端 平衡开销与稳定性
  • 默认租约 8 天(可调整)
  • 到达 50% 租期(4 天)——客户端主动 Request 续租
  • 服务器 ACK → 租期重新从 0 开始
  • 如果到 87.5%(7 天)还没续上——广播 Request 向任意服务器续租(REBINDING,不是重新 DORA)
  • 如果到 100% 仍未获 ACK——释放 IP,回到 INIT 重新走完整 DORA
  • 短租期适合移动办公,长租期适合固定 PC

Relay

DHCP 中继 · 跨子网自动分配

  • DHCP 广播不能跨路由器(路由器不转发广播)
  • 每个子网都装一台 DHCP 服务器?成本高 / 难管理
  • 解决:在路由器接口上启用 ip helper-address
  • 路由器把广播单播转发到指定 DHCP 服务器
  • 一台 DHCP 服务器可服务多个子网
  • 现代企业网的标准做法

Compare

静态 IP vs DHCP · 对比

手工

静态 IP

100 台 PC 一台台配 IP;

容易输错 / 冲突;

→ 维护成本高

自动

DHCP

客户端开机即获IP;

地址统一管理,无冲突;

→ 适合大规模网络

Pros Cons

DHCP 的优缺点

  • 优点　减少管理员工作量、避免地址冲突、集中管理
  • 优点　客户端移动无需重配、租约机制灵活
  • 缺点　单点故障:DHCP 服务器宕机 → 新客户端与到期续租的客户端拿不到地址(租约内不受影响)
  • 缺点　需要冗余:通常部署两台 DHCP 服务器
  • 缺点　广播依赖:每子网都要能广播到达 DHCP(中继解决)

Reserve

保留地址 · 特殊需求

  • 服务器(Web / DB / 邮件) 通常需要固定 IP
  • DHCP 提供保留(Reservation)功能
  • 绑定:MAC 地址 → 特定 IP
  • 服务器请求时,DHCP 总是给它同一个 IP
  • 对客户端透明——配合DNS 名称使用最佳
  • 操作:DHCP 控制台 → 保留 → 新建保留

Case 01

案例 · DHCP 不工作

故障现象

配置好 DHCP 服务器,客户端执行 ipconfig /renew 后无响应——169.254.x.x 地址(APIPA)。

诊断

步骤 1:作用域是否激活?未激活 = 不响应

步骤 2:DHCP 服务是否启动?

步骤 3:是否有排除范围把整个网段都排了?

解决

右键作用域 → 激活;检查服务状态;调整排除范围。

结论

✅ DHCP 故障排查:服务 → 作用域 → 激活 → 范围 → 路由 5 步。

Case 02

案例 · 跨子网拿不到 IP

故障现象

VLAN 20 的 PC 通过路由器连到 DHCP 服务器,拿不到 IP。

诊断

DHCP 广播不能跨路由器——VLAN 20 的广播包到不了服务器所在子网。

解决

在路由器连接 VLAN 20 的子接口上配置:

ip helper-address 192.168.10.1(DHCP 服务器 IP)

结论

✅ DHCP 中继是跨子网的标准做法。
