Scenario

任务情境 · 手工配置太累了

需求

IP 是必备

网络中的主机要相互通信，必须有合适的 IP 地址才能在网络上标识自己。

办法 A

手工设定

由管理员逐台手工设定——可行但费时。

办法 B

自动分配

由网络上的 DHCP 服务器自动给主机分配 IP——更快、更不易出错。

问题

手工的代价

大规模网络下，手工配置给管理员带来巨大工作负担；用户不遵守规则还会导致IP 冲突。

Goal

任务目标

能够在运行 Windows Server 的主机上安装与配置 DHCP 服务。

客户机能够成功获取 IP 地址——DHCP 服务器与客户机协同完成地址分配。

Environment

使用环境

硬件

1 台服务器 + N 台客户机

一台 DHCP 服务器 + 若干客户机；所有机器互相连通。

服务器 OS

Windows Server

服务器操作系统采用 Windows Server 系列。

客户机 OS

Windows

客户机安装 Windows 系统（Win 7 / 10 / 11 均可）。

实践

Packet Tracer 模拟

教学环境下常用 Packet Tracer 模拟——Config → Service → DHCP → On。

Tasks

本课主要任务

  1. 任务一　安装 DHCP 服务
  2. 任务二　配置 DHCP 服务器（地址池、租期等）
  3. 任务三　配置 DHCP 客户机（自动获取 IP / DNS）
  4. 相关知识　DHCP 介绍、工作过程、作用

Task 01

任务一 · 安装 DHCP 服务

步骤

登录服务器

用管理员账号登录 Windows Server 主机。

步骤

添加角色

「服务器管理器」→「添加角色和功能」→「DHCP 服务器」。

步骤

完成安装

按向导完成；安装完成后可在「管理工具」中打开 DHCP 控制台。

步骤

验证

服务列表中显示 DHCP Server 处于「已启动」状态。

Task 02

任务二 · 配置 DHCP 服务器

01

规划地址池

用户数 100，可能扩展到 200。

02

设定范围

IP 范围：192.168.1.1 – 192.168.1.200。

03

子网掩码

255.255.255.0；网关一般设为 192.168.1.254。

04

DNS

DNS 服务器根据实际情况配置（本章示例可暂用 8.8.8.8）。

05

租期

默认 8 天；按需调整（教室环境可设 1 小时便于复用）。

Task 03

任务三 · 配置 DHCP 客户机

步骤

打开网络设置

「控制面板」→「网络和共享中心」→ 适配器属性。

步骤

IPv4 属性

双击「Internet 协议版本 4 (TCP/IPv4)」。

步骤

自动获得

IP 地址：自动获得 IP 地址；DNS：自动获得 DNS 服务器地址。

验证

查看结果

在命令行执行 ipconfig，看到 IP、子网掩码、网关、DNS 均已自动填充。

Background

相关知识

DHCP 是什么？怎么工作的？

What is DHCP

DHCP 介绍

全称

Dynamic Host Configuration Protocol

动态主机配置协议——为网络中的主机自动分配 TCP/IP 配置信息。

角色

服务器 vs 客户机

提供 DHCP 服务的计算机是 DHCP 服务器；不需要手动设置固定 IP 的是 DHCP 客户机。

分配内容

TCP/IP 全套

DHCP 完成客户机的 TCP/IP 配置：IP 地址、子网掩码、网关、DNS 等。

特点

动态 + 集中

地址动态分配、集中管理——降低维护成本、避免冲突。

Process · A

DHCP 工作过程 · 四个阶段

01

DISCOVER

客户端首次登录时没有任何 IP 数据，广播 DHCP DISCOVER 包寻找服务器。

02

OFFER

服务器从尚未租出的地址池中选一个 IP，单播 / 广播回应 DHCP OFFER。

03

REQUEST

客户端可能收到多份 OFFER；它广播 DHCP REQUEST 告知所有服务器——「我选这一份」。

04

ACK

被选中的服务器广播 DHCP ACK，确认租约正式生效。

Process · B

DHCP 工作过程 · 关键细节

!

重传

若客户端在一定时间内没收到响应，会多次重发 DISCOVER 广播。

!

挑选

客户端通常选最先到达的 OFFER——不必挑选最优服务器。

!

拒绝

客户端收到 ACK 后还会ARP 检测该 IP 是否已被占用；冲突则发 DHCPDECLINE 重新申请。

!

续租

租期过半时客户端发起 DHCP REQUEST 续租；超时未续则归还 IP。

Why DHCP

DHCP 的作用

减负

减少管理员负担

不必逐台手工配置 IP；新增主机「即插即用」。

可靠

配置安全可靠

由服务器集中下发，避免手工输入错误、地址冲突、子网掩码错配。

便利

移动用户便利

笔记本在不同子网间漫游时自动获取新子网的 IP。

节约

解决地址不够

通过地址复用提高利用率——尤其在用户多于地址数的场景。

Recap

本章小结
