

# SIIT 42160 教程演示文稿

## 项目简介

本项目是一份计算机网络的交互式演示文稿，采用现代网页技术构建，可通过浏览器直接播放。

## 内容结构

演示文稿共包含 55 张幻灯片，主要内容分为以下几个模块：

**基础概念篇**：介绍网络协议的历史发展脉络，包括早期协议诞生背景、标准化进程以及现代互联网协议体系的演进历程。通过时间轴形式展示从 1970 年代到现代的重要里程碑事件。

**协议分层模型**：深入讲解网络 TCP-IP 模型（网络接口层、互联网层、传输层、应用层）以及与之对应的 OSI 七层模型。每一层都配有详细的协议说明和功能介绍，包括以太网、IP、TCP、UDP 等核心协议的工作原理。

**网络协议详解**：涵盖网络层、传输层、应用层各类重要协议的原理和应用场景，包括 IP 地址分类与子网划分、TCP 三次握手与四次挥手、HTTP/HTTPS 协议机制、DNS 域名解析系统等关键技术点。

**网络架构与设备**：介绍网络设备的工作原理和在协议栈中的角色，包括集线器、交换机、路由器等设备的层次定位和数据处理方式。

## 使用说明

### 环境要求

- 现代浏览器（Chrome、Firefox、Edge、Safari 等）
- 无需服务器环境，直接双击 HTML 文件即可运行

### 操作指南

- **方向键**：切换上一页/下一页幻灯片
- **空格键**：下一页
- **ESC 键**：展开/收起侧边栏导航
- **数字键**：快速跳转到指定页码
- **鼠标滚轮**：上下翻页

### 演示功能

演示文稿支持多种高级功能：
- 幻灯片动画效果
- 进度条显示当前播放位置
- 页码计数器实时显示当前位置
- 侧边栏导航可快速定位任意章节
- 键盘快捷键帮助面板（按 H 键调出）

## 技术实现

本项目基于原生 HTML、CSS 和 JavaScript 开发，不依赖任何第三方框架。采用了以下技术特性：

- **响应式设计**：适配不同屏幕尺寸的展示需求
- **CSS 动画**：实现平滑的幻灯片切换和内容渐显效果
- **语义化结构**：使用 HTML5 语义标签构建幻灯片内容
- **键盘事件处理**：完整的键盘快捷键支持
