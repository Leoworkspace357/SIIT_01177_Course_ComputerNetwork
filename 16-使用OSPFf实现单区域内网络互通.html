Topic

OSPF · 开放最短路径优先

全称

Open Shortest Path First

开放最短路径优先——基于开放标准的链路-状态路由协议。

地位

企业 / 运营商骨干

目前企业网与运营商骨干最常用的内部网关协议（IGP）之一。

替代

RIP 的升级

克服了 RIP 的「慢收敛、传闻路由、跳数限制」等问题。

优势

收敛快 + 大型网络

支持大型网络、收敛快、支持 VLSM/CIDR。

What

OSPF 协议概述

类型

链路-状态

OSPF 是一种链路-状态路由选择协议。

链路状态

接口状态

所谓「链路状态」是指路由器接口的状态：UP / DOWN、IP、网络类型、开销等。

发布

LSA

链路状态信息通过链路状态公告（LSA）发布到网上每台路由器。

汇总

LSDB

每台路由器通过 LSA 建立链路-状态数据库（LSDB）——全网拓扑的「地图」。

Why OSPF

OSPF 的优点

开放

国际标准

基于国际标准，开放性强，被众多网络设备厂商支持。

灵活

支持 VLSM

支持 VLSM 与 CIDR——地址规划无限制。

快速

触发更新

使用触发的路由更新——快速反应网络变化，减小协议流量。

高效

稳定后再算

直接转发路由更新，待路由稳定后再计算——效率更高。

大型

千台规模

支持大型网络——最多 1024 台路由器联合工作，并能优化路由更新。

Area

OSPF 区域 · 层次化设计

概念

区域

OSPF 用区域（Area）为自治系统分段——一种层次化的路由选择协议。

主干

Area 0

区域 0 是 OSPF 网络中必须具有的区域——主干区域（Backbone）。

互联

必须通过 0

其他所有区域必须通过区域 0 互连到一起——非骨干区域不能直接相连。

价值

可扩展性

层次化设计降低 LSDB 规模、减少 SPF 计算开销、提高可扩展性。

L-S Algo

链路-状态路由算法 · 三步走

01

发现邻居

每台路由器发现与之相邻的路由器，并了解对方链路的状态。

02

交换 LSA

每台路由器构造自己的 LSA，并向全网泛洪——最终所有路由器的 LSDB 一致。

03

算 SPF

以自己为根，利用 SPF（Dijkstra）算法算出到达各网络的最短路径，生成路由表。

5 Packets

OSPF 的五种协议报文

报文作用
HELLO发现及维持邻居关系
DDDatabase Description　向邻居描述本地 LSDB 的概要
LSRLink-State Request　向对端请求本端没有或更新的 LSA
LSULink-State Update　向对端发送所需的 LSA
LSAckLink-State Acknowledgment　对收到的 LSU 进行确认

Operation

OSPF 操作 · 四个阶段

01

建立邻接关系

通过 HELLO 报文发现邻居 → 建立邻接（Adjacency）关系。

02

同步 LSDB

通过 DD / LSR / LSU / LSAck 完成链路-状态数据库同步。

03

选择路由

用 SPF 算法算出到达各网络的最短路径，生成路由表。

04

维护路由

持续收发 HELLO 与 LSU——链路状态变化时触发更新。

Basic Config

OSPF 基本配置 · 两步命令

01

启动路由进程

Router(config)# router ospf 　process-id 本地有效，1–65535。

02

宣告网络

Router(config-router)# network

area 。

!

反掩码

inverse-mask 是反掩码（通配符掩码）——与子网掩码「相反」，0 = 必须匹配，1 = 任意。

!

区域 ID

area-id 可以是十进制（0、1）或点分十进制（0.0.0.0、0.0.0.1）。

Example

OSPF 配置实例 · 单区域 Area 0

RTA

进程 1

router ospf 1 network 10.64.0.0 0.0.0.255 area 0

RTB

进程 50

router ospf 50 network 10.2.1.0 0.0.0.255 area 0 network 10.64.0.0 0.0.0.255 area 0

验证

show 命令

show ip ospf neighbor　查看邻居； show ip route ospf　查看 OSPF 路由。

Notes

OSPF 配置注意事项

!

进程 ID 独立

process-id 仅本地有效——同一路由器可启动多个 OSPF 进程，但不推荐。

!

区域必须匹配

同一链路两端接口的 area-id 必须相同——否则无法建立邻居。

!

反掩码精确

反掩码写错会导致接口不参与 OSPF 或错误地匹配过多接口。

!

Hello / Dead

默认 Hello 10s / Dead 40s；可按需调整但两端必须一致。
